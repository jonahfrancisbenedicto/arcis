# Arcis 
Simulates projectiles motion

## Math
Position:
```math
p(t)=\begin{bmatrix} x \\ y \\ z \end{bmatrix}
```

Velocity:
```math
v(t)=p'(t)
```

Acceleration:
```math
a(t)=v'(t)
```

Newton's Second Law of Motion and Acceleration Due to Gravity:
```math
F=ma
F=m\begin{bmatrix} 0 \\ 0 \\ -g \end{bmatrix}

```
