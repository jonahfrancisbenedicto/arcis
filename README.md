# Arcis 
Simulates projectiles motion

## Math
Position:
```math
p(t)=\begin{bmatrix} x \\ y \\ z \end{bmatrix}
```

Velocity:
```math
v(t)=\frac{dp}{dt}
```

Acceleration:
```math
a(t)=\frac{dv}{dt}
```
